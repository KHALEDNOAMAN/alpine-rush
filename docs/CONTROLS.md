# Alpine Rush - Controls & Tips

## Controls
| Key | Action |
|-----|--------|
| Arrow Left/Right | Steer |
| Arrow Up | Accelerate |
| Arrow Down | Brake |
| Space | Drift / Handbrake |
| R | Reset car position |
| P | Pause game |

## Driving Tips
1. **Brake before turns**, not during them
2. **Drift** through sharp corners (hold Space + turn)
3. **Stay on the racing line** - inside of corners
4. **Draft behind AI** rivals for speed boost
5. **Release throttle** briefly before tight turns

## Performance Settings
- Lower shadow quality for 60fps on older machines
- Reduce draw distance in dense forest sections
- Enable anti-aliasing for smoother visuals

## Known Shortcuts
- Turn 3: Cut through the grass patch to save 2 seconds
- Turn 7: Wide entry, tight exit for maximum speed
